## Added

- **PlayStation 5 firmware 13.60 is supported.** The PS5 app is built against an updated payload SDK
  that knows 13.42 and 13.60.
- **Each console reports its firmware in the app,** and you are told when it changes.

## Fixed

- **The PS5 app starts again after a console system update.** Built against an SDK that does not know
  the console's firmware, it could not start at all — Payload Manager reported success and nothing
  happened, with no message and nothing in any log.

## For anyone building this

- `bash ps5-app/update-sdk-wsl.sh --check` says which firmwares your toolchain knows and what is
  available upstream; without `--check` it updates it and keeps the old one.
