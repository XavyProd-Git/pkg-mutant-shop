## Added

- **Updates moved into the Payloads & Homebrews header.** A dropdown lists everything with a newer
  version, with a button per item and **Update all**.
- **The app creates its own folders.** Game and payload folders are made on startup instead of being
  reported as missing.

## Fixed

- A payload the console was plainly running could be shown as unreachable.
- A second PC reported "not on this PC" for files it was carrying.
- Tiles now say which machine can supply a file, not only whether this one can.
