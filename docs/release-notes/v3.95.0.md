## Fixed

- **The PS5 app now works with no PC switched on at all.** If a companion PC that the console had
  seen before was off, the shop could stop answering completely — the page would not load, and
  re-running the payload said it was already running. The console was waiting on that PC, and a
  second PC that *was* on could not help. It no longer waits for any machine that is not there, and
  it stops reaching for one that has gone quiet.
- **The console could end up advertising the wrong address for itself**, which is why a PC could
  report the PS5 as unreachable while the shop was plainly running.
- **The shop draws immediately instead of waiting to find a PC.** Opening it on the console used to
  sit blank while it tried each PC it knew about in turn; it now shows the library straight away and
  picks up a PC in the background.
- **A PC you no longer use is forgotten** rather than being tried on every single load.
- **PS4: the source list no longer shows a green light** for a companion that has gone.
- Several smaller ones: a stuck copy of the app now says so instead of claiming to be running
  normally, and the console can show its own page even if its storage misbehaves.

## Added

- **The PS5 reports how many connections it has served and how long it has been up**, so "the port
  is open but nothing is answering" is something you can actually see.
