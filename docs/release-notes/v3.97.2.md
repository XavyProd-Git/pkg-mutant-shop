## Fixed

- **Two buttons again, and a press that does something.** Pressing anything in Payloads &
  Homebrews opened a row of choices, said "Working…" with a percentage beside it, and then sat
  there — sometimes for the rest of the session, sometimes until a message arrived saying GitHub
  could not be reached. The row had quietly grown extra verbs, and every tile that picked one up
  took two presses instead of one. It is back to what it was: a payload offers **Run**, a package
  offers **Send again** from a PC and **Install** on the console, and something that has not been
  done yet simply happens on the first press. Nothing else is on a tile.
- **Nothing is left saying "Working…".** A download had four hours before anything gave up on it,
  and three separate things could go wrong inside that window without the button ever coming back:
  the transfer stopped moving, the console stopped answering, or it reported a state the app did
  not recognise. Each of those now ends the wait, puts the button back and says which one it was.
- **"Get more" counted things it could not get.** With no PC on the network it read "Get more 5" on
  the PS5 and "Get more 1" on the PS4, and the extras were this app itself and four helper files
  that have no project of their own to download from. The drawer lists only what pressing Download
  would really fetch, so the number beside it is now the number of things you can have.
- **Emulators were being installed twice, into two different folders.** The console was putting app
  folders on the system partition while a PC put them on the main drive — the backup service
  watches both, so the same emulator appeared twice and the newer copy sat beside the older one
  instead of replacing it. The console now says which drive its apps belong on and the app uses
  that answer, and the console refuses to unpack an app anywhere else.
- **A patch or add-on on a USB stick can be installed on the PS4 again.** A package with no base
  game of its own was sorted correctly and then had nothing to press: the button read "Install
  update", was enabled, and answered "No installable base for …". It installs what is actually in
  the package.
- **On the PS4, Run starts the update you just took.** It started the copy built into the app
  instead, left the new one beside it, and the panel credited the new version to the old file — so
  an update looked taken and changed nothing.
- **An update that was not an update.** Itemzflow was offered as `01.08 → 1.08` on the PS4 — the
  same version written two ways — and as `1.14 → 1.08` on the PS5, which is a downgrade with an
  arrow pointing the wrong way. Neither is reported any more.
- **The emulators' helper files are out of the Payloads list altogether.** Four files that live
  inside an emulator's folder and do nothing on their own were listed as payloads named after
  other people's projects, and as rows in the Download drawer that nothing could ever fetch. They
  are still sent with their emulator, exactly as before; they are simply not things you are now
  asked about.
- **"Could not reach GitHub" is in your language, and arrives in eight seconds.** It was raw
  English in all fifteen translations, and it came after a twenty-second wait on a button that said
  "Working…" throughout.
- **A refusal no longer kills a button for the rest of the session.** If something went wrong
  while the console was fetching, the Download drawer would refuse every press afterwards and the
  Update button on a row stayed dead — with no way back but reloading the page.
- **"Check for updates" says when it is busy.** It ignored every press while a check was running —
  which on a console that has not checked before takes tens of seconds — and looked exactly as
  pressable as ever, so it got pressed again and again.
- **One cover no longer stalls the whole console.** Both consoles answer every request in turn, and
  making a card-sized cover was being done in that queue: opening the library stopped everything
  else, once per cover, including the progress of a download you were watching. The covers are made
  in the background now and the full-size art is shown until one is ready.
- **The panel could be emptied by a long version number.** A project that publishes a wordy release
  tag could overflow the console's reply and cut it mid-sentence, and the panel then had nothing to
  show and no reason to give.
- **The PS4 app no longer touches the system's network libraries while it is starting.** It was
  doing so before it had opened its own port, which is the one place in this app where something
  that does not return leaves no shop, no status and no way to see why. It measurably did not help
  with anything, so it is gone from startup.

## Notes

The Payloads & Homebrews panel is the whole of this release. The work that moved it onto the
consoles had changed how it behaved as well, and this puts that back: the two buttons, the single
press, and the honest counts are what the panel did before any of it, now done by the console
itself with no PC on the network.

Both consoles were read live while this was written — the buttons, the badges, the drawers and the
install folders — and the panel's own decisions are now checked by the test suite against the
readings taken off them, rather than against the shape of the code that makes them.
