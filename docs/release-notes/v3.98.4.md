The first public build since 3.97.2, so it carries everything from 3.98.0 to 3.98.4.

Below is what changed, by area. Every change with the measurements behind it is in the
[full changelog](https://github.com/XavyProd-Git/pkg-mutant-shop/blob/master/CHANGELOG.md).

## Fixed

### Performance and artwork

- **The library paints straight away on a console with no PC.** It was asking each title for its
  full-size original instead of the card-sized cover the console had already made. Measured over a
  68-title library: **2.2 MB where 23 MB was being used**, and roughly a megabyte of memory per
  image to decode on top of that.
- **The game panel was doing it a second time**, fetching a full-size image to fill a box 160
  pixels tall — about 340 KB per open, and 25 MB against 2.4 across the titles that have artwork.
  It now uses the cover you already have, so the panel opens with no download at all.
- **Covers that never started now start.** Artwork is loaded as it comes near the screen, which is
  right — but when that decision never arrives the cover simply never appears. Anything that has
  not begun a few seconds after the library settles is now asked for outright.
- **A third of the library stops asking for artwork that is not there.** Titles whose pictures live
  on a PC you have switched off were each firing three requests that could not succeed before
  falling back to initials. The console now says whether it has the picture.

### GitHub connectivity and update checks

- **The newest release is picked correctly.** The release list is not in date order, and the app was
  taking the first entry — so it offered the wrong release as the update, and sometimes reported
  everything current while a newer build sat on the project's own page.
- **A release check and a download no longer get in each other's way.** Each was building its own
  network stack, and two at once fails on every address — which is exactly what happens when you
  open the Payloads panel and then press Update, the commonest thing anyone does with that drawer.
- **Anything that could not be checked now says why.** The drawer used to read "2 could not be
  checked" and throw the reason away, including the one sentence that tells you what to do about it.
  Each one is now named, in the console's own words, with a link to the project's page.
- **kstuff and FPKGi can be checked at all**, and two more projects had no file pattern recorded.

### Sources outside GitHub

- **FPKGi comes from pkg-zone now**, which is where it is actually published — with a **separate
  build for the PS4 and the PS5**, so each console asks for its own. The console reads that page
  itself, so this works with no PC on.
- **A package whose internal version never changes stops looping.** FPKGi has reported 01.00 through
  ten releases, so every check read it as out of date: you took the update, the same 85 MB arrived,
  and the row came straight back. The file's own name is read instead — but only where the internal
  number is demonstrably stale, so the version shown for every other homebrew is unchanged.

### Path corrections

- **A payload you update with no PC now replaces the copy inside Payload Manager.** It was landing
  only in the app's own folder, where Payload Manager never looks — so ShadowMountPlus, kstuff, FTP,
  nanoDNS, OnionHEN, the WebKit installer and this app's own ELF were updated everywhere except the
  place you start them from. It is written under the name already there, so your list keeps one
  entry per payload instead of gaining a second.
- **A new build of the app taken on the console survives a restart.** It used to be cleaned out of
  the app's own payload folder on the next start and offered to you again.
- **The PS4 stops overwriting your own files in GoldHEN's folder**, and a folder app is never sent
  to a path that cannot exist.

### Storage and duplicates

- **A game that is on the console twice is finally visible.** One title was there as a compressed
  backup in one watched folder and an installed app folder in another, and every part of this app
  was written to show one card per game — so there was nothing to act on. The card now says how many
  copies there are and where the other one is.
- **⧉ Clear the duplicate**, in the ⋯ menu, removes the extra copy and keeps the one the console
  actually mounts. It is deliberately not the Delete button: that one removes *every* copy, which is
  right for deleting a game and wrong here.
- **Folder apps report their real size**, instead of 64 KB — the folder's own entry rather than its
  contents, one of them 109.5 MB across 67 files — and no longer describe themselves as compressed
  containers.
- **Deleting a backup removes every copy of it**, and 97 MB of leftovers were cleared off the PS5
  with the cause fixed so they do not build up again.

### Working with no PC at all

- **Every emulator installs and updates from a PS5 with no PC on.** Most of them ship as an
  archive and neither payload could read one, so the Updates drawer turned into a link to somebody's
  release page. Both consoles carry their own decompressor now: one job fetches, opens and places
  the app folder, with one progress bar — and it **merges** into an existing install, so your saves
  and roms are left alone. (A PS4 can open an archive too; what it cannot do is fetch one — see
  below.)
- **The PS4 stops inventing seven USB drives.**

### Clearer and safer

- **Anything that changes the jailbreak layer asks twice**, every time.
- **Run says which file it started**, so "I took the update and it is still offered" can be told
  apart from a problem with the check.
- **The PS4 tells you before you press that it cannot download on its own.** It cannot — that one is
  the console and not the app, and it was chased as far as it goes: the certificates, the system
  modules, the memory given to the security layer, and even having the console's browser fetch the
  file and hand it over. Instead of a tile reading "Working…" for twenty seconds and then a code,
  the row says a PC has to fetch it. **The updates themselves still appear**, because the page reads
  the projects' releases itself.

### Translations

- **New strings, in all fifteen languages**, for everything above that says something new.

| `PKG-MUTANT-SHOP-3.98.4.zip` | all three, with checksums |
