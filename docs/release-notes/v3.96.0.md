## Fixed

- **Sending a game to a console is about six times faster.** A game that lived on the PC you pressed
  Install from was being *pushed* to the console instead of the console *fetching* it — the fast
  route existed but could never be reached. Measured on real hardware: **16.9 MB/s before,
  111.7 MB/s now**. A 35 GB game arrives in a little over two minutes; a 112 GB one goes from
  about **1 hour 50 minutes to roughly 17**.
- **Both consoles now move data in 1 MB blocks and ask for a proper network buffer.** On its own
  that took a PS5 write from 42.7 MB/s to 108.7 — the speed of the cable. Internal storage went from
  16.1 to 74.3 MB/s, so it was never the drive.
- **A large install could be cut off part-way.** While the console was busy filing away what it had
  already received, the PC gave up sending after 30 seconds — and the install failed with nothing on
  screen to say why.
- **PS4: a transfer could throw itself away near the end** over a perfectly normal condition.
- **The Payloads & Homebrews panel was missing updates that were really there.** It only ever asked
  GitHub for the latest *stable* release, and most of these projects publish test builds — so an
  update you could see on the project's own page was invisible here. It now finds them, and marks a
  row clearly when it is a pre-release so the choice is yours.
- **Six payloads could never be offered an update at all**, because the file that records their
  versions was not being included in the app.
- **The panel now tells you when it cannot tell.** Previously an item it could not compare looked
  identical to one that was up to date. Each is now listed with the reason and a link to the
  project's page.
