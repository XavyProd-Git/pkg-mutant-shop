## Fixed

- **The phone layout was wrong, not just tight.** Parts of the top bar — the install queue, the
  Payloads & Homebrews button, the console picker — were being drawn *above* the logo, in no useful
  order. The top bar is now four rows, and more than half the screen is no longer spent before the
  first game.
- **Rows that scroll sideways now look like it.** The filter chips could not be scrolled at all, so
  the last one was unreachable, and four of five storage tiles sat off the edge of a phone with no
  hint they were there.
- **The panel's close button is back where you can reach it,** instead of alone on a third row.
- **The library summary drops what a phone cannot use** — a Windows folder path and which PC is
  serving — and keeps the title count.

## Changed

- **The README explains each device.** New sections for the PS5, the PS4, a PC and a phone, and a
  section on sending payloads and homebrews — which the app has always done and the page never said.
- **The docs stop treating the PS5's behaviour as both consoles'.** The install verdict, the install
  steps, what each artifact carries and whether cheats can be applied all differ between the two,
  and now say so. The PS4 applies cheats; that had been documented as impossible.
- **Credits corrected.** The notices said the app ships no part of the jailbreak stack while also
  listing two of those parts as embedded. Payload Manager and kstuff are redistributed inside the
  PS5 payload, under their own licences.
