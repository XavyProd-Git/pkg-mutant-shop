## Added

- **The app updates itself, on its own.** It checks for a newer build in the background, downloads
  and installs it, and then tells you it is ready — it does not close a window you are using. The
  **Payloads & Homebrews → Updates** panel shows *"Version X is ready"* with a **Restart now**
  button, from any device: a PC, a console, or your phone.
- **A single zip download.** Each release now also carries
  `PKG-MUTANT-SHOP-<version>.zip` with all three files, their checksums, and a short read-me. The
  individual files stay exactly where they were.

## Fixed

- **An out-of-date app could report that everything was up to date.** The Updates list compared the
  payload file in your folder and never the app doing the comparing, so a PC whose folder was
  already current said nothing was available while running a build several releases old — and the
  only way out was copying the exe across by hand. It now checks both, and says which one is behind.

## Changed

- **Restarting after an update is yours to choose.** Previously the app restarted itself the moment
  a new build was in place. Set `updates.auto_restart` to `true` in `config.json` to get that back.
- **Supported PS5 firmware is listed in full** — 67 versions, from the launch build to 13.60 — and
  the README no longer names a particular jailbreak: the app needs Payload Manager (PS5) or GoldHEN
  (PS4) to be running and does not care how you got there.
