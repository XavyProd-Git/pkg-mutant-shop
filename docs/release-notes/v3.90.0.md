## Added

- **The Windows app updates itself.** Updating the PKG MUTANT SHOP tile now replaces the Windows app
  as well, not only the console's file.

## Known at the time

- Updating from a build older than 3.90.0 still replaces only the console file, so one copy across by
  hand is needed to reach this version.

## Download

| | |
|---|---|
| `PKG-MUTANT-SHOP.exe` | Windows companion |
| `PKG-MUTANT-SHOP.elf` | PS5 — firmware up to 13.40, load from Payload Manager |
| `PKG-MUTANT-SHOP-PS4.elf` | PS4 — FW 13.52, load through GoldHEN |

Already running it? Open **Payloads & Homebrews → Updates**.
