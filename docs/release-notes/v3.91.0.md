## Added

- **The app restarts itself after updating itself.** Set `updates.auto_restart` to `false` in
  `config.json` to be told to reopen it instead.

## Fixed

- **An app you deleted no longer shows as installed.** The panel asked the console once and then kept
  answering from that first reply for as long as you were looking at it.
- **Updating this app actually sticks.** On a PC that did not hold our PS4 payload, the update
  reported success and changed nothing.
- **Sending our own payload to a console works again.** The transfer was skipped whenever the file
  was already the same size, and our builds are the same size from one release to the next.
- **The version shown for this app is the one you have,** not the one recorded when the app was built.
- **"Not installed" is no longer printed when the app cannot tell,** and a press on an unknown state
  asks before installing over the top.
- **The Updates list re-checks instead of assuming** the update worked.
