## Fixed

- **Every emulator can be installed and updated from the console itself again.** With no PC on the
  network, eight of the nine homebrew tiles on the PS5 — and all four on the PS4 — answered a press
  with the single word "Installed" and did nothing at all. The console decides what it is holding
  from a list that only ever counted `.pkg` files, so a folder app, which leaves no package behind,
  could never be recognised and its tile had nothing to offer. All six emulators now install,
  re-install and update from the tile with the PC switched off, which is what the front page has
  always said: *a console on its own is not a degraded mode*.
- **A press on something that changes the jailbreak layer asks twice, as it has always said it
  does.** It said so and asked once. The sentence for the second ask — *"Press again to send it"* —
  has been sitting in all fifteen languages the whole time with nothing calling it, and the
  server's own matching refusal could never fire because the app told it the question had already
  been asked. Now the first press on the button arms it and turns it amber, and only the second
  sends anything. Everything else still acts on the first press.
- **Run says which file it started.** The front page promises that Run *checks first that the copy
  really is the one you are looking at*, and nothing told you either way: the answer was one fixed
  sentence whichever of two same-named files had been handed over. It now names the file and its
  size, so it can be checked against the tile.
- **97 MB of leftovers removed from the PS5, and it will not build up again.** Nothing ever cleaned
  our own folder, so every rename of a payload, every update taken and every finished download left
  a file behind for good. On the first start this release removed an old copy of this very program
  from the payload folder (45.8 MB), a stale duplicate of a payload the app ships, a backup of its
  own payload that nothing reads (47.3 MB), two finished downloads — one of them a PS4 payload
  sitting on a PS5 — and a version note for a file that was gone. Each removal is written to the
  log with the reason. Only our own folder is swept, and only files nothing reads: your apps, games
  and backups are never touched.
- **An update you took on the console is no longer undone by the next restart.** The app refreshes
  the payloads it ships on every start, and a payload updated on the console lands under that same
  name — so the shipped copy quietly went back, while the note beside it kept reporting the version
  you had taken. The two no longer disagree: a payload you updated stays, and the log says it was
  kept.
- **The PS4 no longer overwrites your own files in GoldHEN's folder.** It filled `/data/payloads`
  with the payloads it ships, which is useful when the folder is empty — but it also replaced any
  file of a different size on every single start, so your own build of ftpsrv was silently
  overwritten and nothing said so. It now only ever fills an empty slot.
- **A folder app is never sent to a path that cannot exist.** With no destination to hand, the app
  fell back to a PS5 path and would have used it on a PS4, where nothing mounts a folder as a title
  at all. The console says where its apps belong, or says that it mounts none, and the app refuses
  with a sentence instead of writing somewhere it invented.
- **Finding a PC mid-session now refreshes this panel too.** Adopting a companion changes every
  answer the panel shows — the tabs, and the buttons on every tile — and it was the one view not
  refreshed when that happened.

## Notes

The Payloads & Homebrews panel was audited end to end for this release: every control pressed in
all three lanes with the app's own request layer swapped for a recorder, so each press could be
read as the request it would have sent without anything being installed; and every folder the app
writes to, on both consoles, walked and measured.
