## Fixed

- **The PS4 could stop accepting installs,** because it reported itself busy after installing its own
  home-screen icon.
- **Asking what an install would do no longer performs one.**

## Checked on hardware

- Every bundled payload starts from the console itself, with no PC on the network.
- Every homebrew install was exercised on the console it belongs to.
