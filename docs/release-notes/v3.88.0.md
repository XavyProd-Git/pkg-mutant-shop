## Fixed

- **"Installed" now means the game is really there.** Leftover artwork from a failed install was
  being counted as an install — 29 titles on a real console that were never installed.
- **An install no longer says "Done" before it has happened.** It says queued, and the queue reports
  how it ends.
- **The app's own tile shows the version that is running,** not the one recorded when the build was
  made.
- **A second PC can take updates** instead of refusing every one it offered.
- **The app recovers when a console changes both address and identity,** instead of asking a dead
  address for ever.
- **A console with no PC no longer claims everything is up to date** when it could not check at all.
