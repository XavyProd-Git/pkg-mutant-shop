## Fixed

- **Restarting after an update left part of the old copy behind.** Each restart abandoned about
  40 MB of temporary files that nothing could clean up afterwards — 169 folders had built up on one
  PC here. Existing leftovers are removed as the app updates itself from now on.
- **Two buttons in the Updates panel could appear at once, and only the top one worked.**

## Added

- **The app checks that it started properly, and tells you if it did not.** A copy that has not
  unpacked completely used to look like a copy with nothing to do: the Updates list was empty, and
  it could not see its own new version. It now says so at the top of **Payloads & Homebrews →
  Updates**, on any device, with a **Restart now** button that fixes it.
